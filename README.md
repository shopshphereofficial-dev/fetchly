# Fetchly

A personal-use media browser and downloader for Android, powered by
yt-dlp (via youtubedl-android) with aria2c multi-connection fast downloads.

## Features
- Home: paste a link, choose real available qualities, download
- Downloads: live progress, cancel, retry (resume where the server supports it), delete, share
- Music: audio library with in-app player (queue, shuffle, repeat)
- Browser: in-app web browser with bookmarks, history, cookie-based login support
- Settings: light/dark/system theme, English/Hindi/Urdu, Wi-Fi-only mode, engine updater

For personal use of your own content only. Do not redistribute downloaded content.

## Build
APK is built automatically by GitHub Actions - see `.github/workflows/build.yml`.
